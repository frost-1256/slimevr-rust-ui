Licensed under the SIL Open Font License, Version 1.1.

The upstream variable font (google/fonts, ofl/notosansjp/NotoSansJP[wght].ttf)
was instanced at weight 400 and subset with pyftsubset (fonttools) to the
codepoint ranges a Japanese desktop UI needs: Latin-1, general punctuation,
arrows, circled numbers, geometric shapes, dingbats, CJK punctuation, kana and
CJK unified ideographs. No glyph outlines were otherwise modified.

Full license text (authoritative): https://openfontlicense.org/
Upstream font: https://github.com/google/fonts/tree/main/ofl/notosansjp

The font is embedded into the executable (via include_bytes!) as a fallback
typeface so that Japanese text renders on systems without Japanese fonts.

The upstream variable font (google/material-design-icons,
variablefont/MaterialSymbolsOutlined[FILL,GRAD,opsz,wght].ttf) was subset with
pyftsubset (fonttools) to the eight navigation glyphs this UI uses
(U+E41C, U+E51E, U+E6B1, U+E871, U+E875, U+E8B8, U+EB8E, U+F053), keeping the
variable axes untouched. No glyph outlines were otherwise modified.
